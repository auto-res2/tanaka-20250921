The core methodology involves amortized Bayesian inference implemented by fine-tuning a pretrained Large Language Model (LLM) as a GFlowNet policy. GFlowNets are diversity-seeking reinforcement learning algorithms that learn to sample sequences (latent variables Z) with probability proportional to a given reward function. The reward function is defined as the joint likelihood 𝑝LM(𝑋𝑍𝑌) (or a tempered version), effectively training the GFlowNet policy to sample from the intractable posterior 𝑝LM(𝑍|𝑋,𝑌). The training utilizes a modified subtrajectory balance (SubTB) objective. The GFlowNet policy is initialized as a copy of the pretrained LLM and fine-tuned using LoRA for hardware efficiency. Training mini-batches are composed from the current policy, a tempered version of the policy, and a replay buffer storing past trajectories. Depending on the task, the GFlowNet policy can be conditioned on the input 𝑋 alone (for reasoning tasks to predict 𝑌 for unseen 𝑋) or on both 𝑋 and 𝑌 (for tasks like infilling where 𝑌 is available). For prediction, Bayesian model averaging is used by drawing multiple 𝑍 samples from the GFlowNet and then sampling 𝑌 from the base LLM, with a majority vote for the final answer. The approach is also framed as the E-step of an EM algorithm.
