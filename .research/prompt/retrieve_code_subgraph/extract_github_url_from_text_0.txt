# Paper Outline
The core methodology is an LLM-driven objective discovery pipeline. It iteratively prompts a Large Language Model (GPT-4) to propose and implement new preference optimization loss functions as PyTorch code. The process starts by providing the LLM with established loss functions and their performance, along with problem details and an example output format. Each proposed objective function is then validated with unit tests; if invalid, the LLM receives error feedback and resamples. Valid functions are used to finetune an LLM, and their performance is evaluated on a predefined downstream task (MT-Bench). This performance metric is fed back to the LLM as in-context examples, allowing it to iteratively refine its proposals by exploring variations, tuning components, and composing insights. The loss functions are designed to operate on the log ratio difference ρ = log(πθ(yw|x)/πref(yw|x)) - log(πθ(yl|x)/πref(yl|x)).
